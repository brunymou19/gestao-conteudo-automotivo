# 10 — Pendências e dúvidas para o próximo contato com o cliente

Cada item abaixo tem uma *Issue* correspondente no GitHub (veja o rótulo `duvida-cliente`).

1. O limite de 2 publicações por dia é **restrição obrigatória** ou apenas **aviso**?
2. Existe **intervalo mínimo** entre duas publicações?
3. Quais **estados** devem existir no fluxo de produção?
4. Como registrar solicitações de eventos (divulgação antecipada, cobertura durante/após)?
5. Que informações registrar sobre oportunidades, contatos externos e parcerias?
6. Quais os **nomes das ~12 novas editorias** e como classificar os conteúdos?
7. A agenda só **visualiza** datas ou também permite **reorganizar/reagendar**?
8. Os materiais ficam **armazenados no sistema** ou o sistema só organiza **referências** a arquivos existentes?
9. Quais informações/registros seriam **mais prejudiciais se perdidos**?
10. Qual o comportamento esperado se o sistema ficar **indisponível** durante uma solicitação importante?
11. Quais tarefas de edição poderiam usar **IA** e quais aplicativos o cliente pretende usar?
12. Qual a **frequência semanal** desejada e quais dias teriam conteúdos fixos?
